# Brain deviation scores derived from normative modelling identify dimensions of psychopathology in children and adolescents

Analysis code for the above study.

## Contents

- **`sCCA/`** — code using sparse canonical correlation analysis (sCCA) to build multivariate associations between brain structure and CBCL psychopathology scores.
- **`Model_Generalization/`** — sCCA model parameters obtained from this study's discovery dataset, applied to an independent dataset for validation.
