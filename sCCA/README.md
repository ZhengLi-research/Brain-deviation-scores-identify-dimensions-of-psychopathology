# Sparse Canonical Correlation Analysis (sCCA): Brain Deviation Scores/Conventional Brain Structure × CBCL Psychopathology

This repository contains the R / R Markdown code for a sparse canonical correlation analysis

that identifies multivariate associations between Brain Deviation Scores/Conventional Brain Structure and child/adolescent psychopathology scores (CBCL).

## Method overview

The analysis pipeline follows the standard sCCA workflow:



1. **Nuisance regression** — age and sex are regressed out of CBCL item scores.

2. **Penalty grid search** — a 10 × 10 grid of L1 penalties (`penaltyx`, `penaltyz`) is

   Evaluated on 10 repeated 2/3 splits, stratified by p-factor score provided by the Reproducible Brain Charts (RBC). Details of the calculation are provided in DOI: 10.1016/j.neuron.2025.08.026.; the pair with the

   highest mean canonical correlation is selected.

3. **Component selection** — a scree plot of variance explained per component is used to

   choose the number of retained canonical variates (default: 4).

4. **Permutation test** — 1,000 row-wise permutations of the behavior matrix yield empirical

   p-values per component, followed by Benjamini–Hochberg FDR correction.

5. **Bootstrap inference** — 1,000 bootstrap resamples (stratified by p-factor) provide

   confidence intervals for brain (u) and behavioral (v) loadings.

The core model is fit with `PMA::CCA()` (Witten, Tibshirani & Hastie, 2009).

## How to run



1. Place your input CSVs in `Input/`.

2. Open `sCCA.Rmd` in RStudio.

3. Click **Knit** — the working directory defaults to the folder containing the `.Rmd` file.

   If you need to run from a different directory, uncomment and set

   `knitr::opts_knit$set(root.dir = "...")` in the `setup` chunk.

4. Output figures (`scree_plot.png`, `cor_plot.png`) and `.RData` result files are written

   to the project root.
